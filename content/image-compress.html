How to compress an image to a specific KB size

  1. Upload your photo with the upload box above. JPG, PNG, WEBP and other common image types work.
  2. Choose a target size: a preset (20 KB, 50 KB, 100 KB, 200 KB, 500 KB or 1 MB) or any value from 10 KB to 2000 KB with the slider.
  3. Press Compress (Keep Sharp) and check the result size and preview.
  4. Download the JPG and upload it to your form.

Use the same steps for your signature. Signature limits are usually much smaller than photo limits, so pick a lower target such as 20 KB if the form asks for it.

Why is my photo so much bigger than the form allows?

A modern phone camera saves photos at 12 megapixels or more, so a single picture is often 3 MB to 8 MB. Many exam, bank and job portals still ask for 20 KB to 200 KB. Cutting quality with one blunt slider usually leaves the face blurry, which is why a size-targeted compressor gives a cleaner result.

How this compressor reaches your target size

File size depends on three things: pixel dimensions, JPEG quality and file format. This tool adjusts the first two together instead of guessing.

  • It first limits the long side of the image. Small targets use a smaller maximum (about 1280 pixels for 100 KB and below) because a tiny file does not need a huge image.
  • It then tries up to eight passes. If the file is too big it lowers the quality a little, and only shrinks the dimensions when quality alone is not enough.
  • It stops as soon as the file is under your limit and close to it, so you do not lose more sharpness than necessary.

The output is always a JPG. Transparent areas in a PNG are filled with white, so this tool is not suitable if you need to keep transparency.

Which size should I choose?

Limits differ for every exam, bank and portal, and they can change between notifications. Always read the photo and signature rules in the official notification and note both the size range and the pixel dimensions. Some portals also set a minimum size, so a file that is too small can be rejected just like one that is too large. If the portal needs exact pixel dimensions, resize the image first and compress it second.

Tips for a sharper result

  • Start from a photo taken in daylight or bright indoor light, facing the camera, against a plain wall.
  • Avoid dark, grainy or cluttered photos. Noise and busy backgrounds use up the file size budget.
  • If a form asks for JPG or JPEG, the downloaded file is already in that format.
  • Keep your final photo and signature in a clearly named folder so they are ready for the next application.

Is it safe to compress my photo here?

Photos and signatures for official forms are personal documents. This tool processes the image inside your browser using the canvas feature, so the file stays on your device and is not sent to a server. Closing or refreshing the tab clears it from memory.

Frequently asked questions

Why is the result not exactly my target size?

The tool aims to land close to the target without going over it, so the result is usually slightly below your limit. Very simple images can end up much smaller than the target.

What if the result is still bigger than my limit?

This can happen with very detailed photos. The tool shows a warning in that case. Choose a lower target, for example about 80% of your limit, and compress again.

Does it work on my phone?

Yes. It runs in any modern mobile or desktop browser and does not need an app or an account.

Will the image quality drop?

Any compression removes some detail, but the tool keeps quality as high as the target allows. For a 20 KB target the image will be smaller and softer than for a 500 KB target, because the file has far less room.
