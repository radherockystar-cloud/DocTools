How to extract pages from a PDF

  1. Upload your PDF. The tool shows how many pages it has.
  2. Type the pages you want in the box, for example 1-3, 5.
  3. Press Extract Pages.
  4. Download the new PDF that contains only those pages.

How to write the page numbers

  • 5 means page 5 only.
  • 2-4 means pages 2, 3 and 4.
  • 8- means page 8 to the last page.
  • 1-3, 7, 10-12 combines several parts. Separate them with commas.

The pages are saved in the order you type them, so 5, 1-2 gives page 5 first, then pages 1 and 2. If a number is wrong or higher than the page count, the tool tells you what to fix.

When this is useful

  • An application accepts only a few pages, or only one document out of a long scan.
  • You want to remove blank or unneeded pages. Type the pages you want to keep.
  • You need to send just one section of a large PDF.
  • You want a smaller file. Fewer pages usually means a smaller PDF.

Things to know

  • The result is one new PDF with all the pages you picked. To get several separate files, run the tool once for each part.
  • Your original file is not changed.
  • Password-protected PDFs are not supported. Remove the password first.
  • Pages are copied as they are, so text and images keep their quality. Links or bookmarks that point to pages you removed may stop working.

After extracting, you can join pieces from different files with the PDF merge tool, or reduce the size with the PDF compressor.

Is my PDF uploaded?

No. The pages are extracted in your browser and the PDF is not sent to our servers. See the privacy policy.

Frequently asked questions

Can I remove pages instead of selecting them?

Type the pages you want to keep. For example, in a 10-page PDF, 1-4, 6-10 removes page 5.

Why do I get an error about page numbers?

The numbers must be between 1 and the number of pages shown, and ranges must go upward, like 2-5, not 5-2.

Will the page order be kept?

Pages follow the order you type. Type them in ascending order to keep the original order.
