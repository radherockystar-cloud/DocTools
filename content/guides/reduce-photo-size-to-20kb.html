Many online forms ask for a photo or signature below a size limit such as 20 KB, 50 KB or 100 KB. A photo straight from a phone camera is usually several megabytes, so it will be rejected until you shrink it. This guide explains why photos are so large and how to bring one down to a limit without turning it into a blur.

Why a phone photo is so big

File size depends mainly on three things: how many pixels the picture has, how strongly it is compressed, and its format. A 12 megapixel photo has millions of pixels, and each one has to be stored. A portal that wants 20 KB is asking for a file that is often more than a hundred times smaller than your original. You reach that by reducing the number of pixels and by compressing, not by one setting alone.

Step by step

  1. Read the requirement. Note the file type (usually JPG or JPEG), the maximum size in KB, any minimum size, and the pixel dimensions if the form gives them.
  2. Fix the shape and pixel size first. Use the image resizer with the width and height from the form. It crops to the right shape before resizing, so faces are not stretched.
  3. Then reduce the file size. Open the image compressor, choose the target (for example 50 KB) and compress. The tool tries to land close to the target without going over it.
  4. Check the result. Look at the preview and the file size. If the face is still clear and the size is within the limit, download it.

What makes the file smaller without ruining the picture

  • Fewer pixels. A photo that is 350 × 450 pixels needs far less data than one that is 3000 × 4000. If the form allows it, do not keep extra pixels.
  • A plain background. Smooth areas compress well. A busy background uses up the size budget that your face needs.
  • Good light. Grainy, dark photos hold a lot of noise, and noise is expensive to store. A well-lit photo stays sharper at the same size.
  • Tight framing. Crop away empty space so the pixels you keep show you, not the wall.
  • Starting from the original. A photo that was already sent through a chat app has been compressed once. Compressing it again loses more detail.

If the result is still too large

Pick a target a little lower than the limit, for example 80% of it, and compress again. If the file is still too large, check that the pixel size is not larger than needed, and try a photo with a plainer background.

If the file is too small

Some portals also set a minimum size. A very small file can be rejected just like a large one. In that case choose a target that sits inside the allowed range, for example the middle of it, rather than the smallest possible value.

Signatures

Sign with a dark pen on plain white paper, photograph it in even light, and crop close to the signature. Signatures are usually a wide, short shape, so use the dimensions on your form with the resizer, then compress to the size limit. The limit for signatures is often smaller than for photos, so check it separately.

Before you upload

  • Open the downloaded file and confirm the face or signature is clear.
  • Check the extension is the one the portal asks for, such as .jpg.
  • Keep the original photo. If the portal rejects the file, you can start again from it.

Rules differ between portals and change over time, so always follow the latest official notification for your form. All the tools mentioned here run in your browser, so your photo is not uploaded to our servers.
