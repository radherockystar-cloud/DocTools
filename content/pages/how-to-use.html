Every tool on FreeDocTools works the same way: choose a file, choose a setting, press the button and download the result. Files are processed in your browser and are not uploaded. This guide shows which tool to use for common jobs and what to expect. For longer explanations, see the guides.

Common jobs, step by step

Prepare a photo for an online application

  1. If the background is not suitable, use the background remover and choose a plain colour.
  2. Set the exact pixel size with the image resizer.
  3. If the form has a size limit in KB, use the image compressor last.
  4. If it needs JPG, check the name of the downloaded file ends in .jpg, or use the image converter.

Prepare a signature

  1. Sign on plain white paper and photograph it in good light.
  2. Resize it with the Signature preset or the size on your form.
  3. Compress it to the size limit on your form.

Send several documents as one PDF

  1. Turn photos of documents into a PDF with the images to PDF tool.
  2. Join your PDFs with the PDF merge tool in the order the portal wants.
  3. Reduce the file with the PDF compressor if it is too large.

Keep only some pages of a PDF

Use the PDF page extractor and type the pages you need, like 1-3, 5.

Copy the text from a photo

Use the text extractor, choose the language of the text, and press Copy Text after the scan.

Before you upload to a portal

  • Read the official notification and note the required file type, size in KB and pixel size.
  • Open the downloaded file and check it looks right before uploading.
  • Keep your original files. The tools never change them, but it is good practice to keep a backup.

Troubleshooting

A tool does not respond or the page is slow

Large files need a lot of memory, especially on older phones. Close other tabs, refresh the page and try a smaller file.

My photo will not open

Some iPhone HEIC photos and raw camera files are not supported by browsers. Export them as JPG from your photo app first.

The background remover or text extractor takes a long time the first time

They download an AI model or language data on first use. This needs an internet connection and can be slow on mobile data.

The portal still rejects my file

Check the exact rules again: type, size, pixels and file name. If the problem remains, tell us on the contact page.
