What you can do on FreeDocTools

FreeDocTools is a set of free tools for the small file jobs that online forms keep asking for. Each tool has its own page with step-by-step instructions, tips and honest notes about its limits.

  • Compress an image to a size such as 20 KB, 50 KB or 100 KB.
  • Resize a photo or signature to exact pixels, like 350 × 450.
  • Convert an image between JPG, PNG and WEBP.
  • Remove a background and choose a new colour or picture.
  • Compress a PDF, merge PDFs, extract pages or turn photos into a PDF.
  • Copy text from a photo with OCR in English, Hindi and other languages.

Why it runs in your browser

Photos, signatures, mark sheets and ID copies are personal. The tools open and change your files on your own device, so they are not sent to our servers. Two tools download extra data the first time you use them: the background remover downloads an AI model, and the text extractor downloads language data. Your files are not part of those downloads. Read the privacy policy and the security page for details.

A typical workflow for an online application

  1. Read the official notification and note the file type, size in KB and pixel size.
  2. Fix the background if needed, then set the exact pixel size.
  3. Compress the file to the size limit and check that it still looks clear.
  4. For documents, turn photos into a PDF, merge them in the right order and compress if needed.

The how to use guide walks through these jobs with links to every tool.

Honest limits

  • Every portal sets its own rules and they change, so we cannot promise that a file will be accepted. Always check the latest notification.
  • Compression always removes some detail. The tool pages explain what each option does.
  • Very large files can be slow on older phones because everything is processed on your device.
