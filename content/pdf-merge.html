How to merge PDF files

  1. Add two or more PDF files with the upload box above. You can add more files later.
  2. Check the order in the list. Use the ↑ and ↓ buttons to move a file, or ✕ to remove it.
  3. Press Merge PDFs.
  4. Download the merged file. It contains all pages of the first PDF, then all pages of the second, and so on.

When merging is useful

  • An application allows only one PDF upload but you have several documents, such as a certificate, a mark sheet and an ID.
  • You scanned a document page by page and want a single file.
  • You want to send one file by email instead of many attachments.

If your pages are photos, first turn them into a PDF with the images to PDF tool, then merge them with your other PDFs.

Order matters

The files are joined in the order shown. Many portals expect documents in a specific order, so check the instructions and arrange the list before you merge. If you get the order wrong, press Merge different files or change the order and merge again. The original files are never changed.

File size after merging

The merged file is usually close to the total size of the files you added. If a portal has a size limit, merge first and then use the PDF compressor on the result. You can also reduce the number of pages first with the page extractor.

Limits to know about

  • Password-protected PDFs cannot be merged. The tool tells you which file is protected, and you need to remove the password first.
  • Very large files, or many files at once, use a lot of memory and may fail on older phones. Merge in smaller groups if that happens.
  • Bookmarks and some interactive form features may not be carried over into the merged file.

Is my PDF uploaded?

No. The files are combined in your browser and are not sent to our servers. See the privacy policy.

Frequently asked questions

How many files can I merge?

There is no fixed limit, but your device's memory decides how large a job it can handle. Try fewer files at a time if the page becomes slow.

Can I merge only some pages of a PDF?

First extract the pages you need with the PDF page extractor, then merge the result with your other files.

Does merging reduce quality?

No. Pages are copied as they are, so text and images are not recompressed.
